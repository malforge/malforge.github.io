## Summary

```csharp
public static float NAVMESH_CELL_SIZE
```

Recast horizontal cell size. Smaller = finer navmesh detail (narrow stairs become traversable) at quadratic memory/CPU cost. An odd number of cells per 2.5 m block, so every block of a base sits at the same lattice phase.
