## Summary

```csharp
public bool CanSeekCharacters
```

Whether a character may be inherited as this ammo's homing target. Off means a locked character is not a usable target: the missile is dumb-fired, and a launcher with Require Target Lock refuses the shot.

## Returns

[bool](https://docs.microsoft.com/en-us/dotnet/api/System.Boolean?view=netframework-4.6)
