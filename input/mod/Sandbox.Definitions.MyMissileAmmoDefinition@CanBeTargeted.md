## Summary

```csharp
public bool CanBeTargeted
```

Whether turrets running with the Target Missiles option on may pick this ammo as a target. Turn it off for ammo that only nominally is a missile - slugs and cannon shells - so turrets keep shooting at real threats.

## Returns

[bool](https://docs.microsoft.com/en-us/dotnet/api/System.Boolean?view=netframework-4.6)
