## Summary

```csharp
public bool DynamicCaster { get; set; }
```

Whether the entity moves on its own, apart from any grid - a dropped item, a held tool. Read once, when the render object is created: set it before the entity is added to the scene.

[bool](https://docs.microsoft.com/en-us/dotnet/api/System.Boolean?view=netframework-4.6)
