## Summary

```csharp
public bool GroupLightDummies
```

Marks the block's own light dummies as effects-only and lights the block with a single source added at their center, so a cluster of dummies costs one lit and shadowed light instead of one per dummy.

## Returns

[bool](https://docs.microsoft.com/en-us/dotnet/api/System.Boolean?view=netframework-4.6)
