## Summary

```csharp
public long BlockEntityId
```

Entity id of the block the action runs on, or of the block whose grid owns the group. Set for [BlockAction](VRage.Game.ModAPI.MyToolbarItemKind@BlockAction) and [GroupAction](VRage.Game.ModAPI.MyToolbarItemKind@GroupAction) . The entity need not be loaded on this machine, on either a read or a write.
