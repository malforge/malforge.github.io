## Summary

```csharp
public static float NAVMESH_MIN_AGENT_CLIMB
```

Floor on the navmesh climb of humanoid (door-opening) agents, for platforms whose cells or RecastDetour library cannot pass a stair tread at the agent's own climb. Wildlife keeps its own value.
