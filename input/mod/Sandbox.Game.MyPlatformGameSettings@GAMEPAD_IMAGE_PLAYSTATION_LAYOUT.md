## Summary

```csharp
public static bool GAMEPAD_IMAGE_PLAYSTATION_LAYOUT
```

True when [GAMEPAD_IMAGE](Sandbox.Game.MyPlatformGameSettings@GAMEPAD_IMAGE) shows a PlayStation pad, which has the D-pad and the left stick in the opposite positions to the Xbox pad the controller scheme labels are laid out for.

[bool](https://docs.microsoft.com/en-us/dotnet/api/System.Boolean?view=netframework-4.6)
