## Summary

```csharp
public MatrixD FindBotStandWorldMatrix(MyCharacter character)
```

World matrix a bot should stand at next to this seat, placed the same way a bot leaving the seat is. Works for a seat the bot never sat in, e.g. one too damaged to be used.

## Returns

[MatrixD](VRageMath.MatrixD)

* MyCharacter <sub>prohibited</sub> character
