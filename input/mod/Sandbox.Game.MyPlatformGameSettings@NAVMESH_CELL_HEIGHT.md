## Summary

```csharp
public static float NAVMESH_CELL_HEIGHT
```

Recast vertical cell size. An edge up to one cell above the agent's climb still connects, so this bounds how closely the navmesh follows the highest step an NPC can mount. An even number of cells per 2.5 m block.
