## Summary

```csharp
public static bool CHECK_CONTROLLER_ID_IN_BINDINGS
```

When true, joystick control bindings are matched against the source device slot so two devices can bind the same axis/button to different controls. Off (default) keeps single-device behavior on platforms that support only one controller.

## Returns

[bool](https://docs.microsoft.com/en-us/dotnet/api/System.Boolean?view=netframework-4.6)
