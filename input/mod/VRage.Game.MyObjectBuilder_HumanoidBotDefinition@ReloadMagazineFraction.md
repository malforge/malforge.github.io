## Summary

```csharp
public float ReloadMagazineFraction
```

Fraction of the magazine capacity (0..1) at or below which a bot holding a rifle or pistol reloads instead of shooting the last rounds; 0 reloads only when empty. Launchers reload only when empty.

## Returns

[float](https://docs.microsoft.com/en-us/dotnet/api/System.Single?view=netframework-4.6)
