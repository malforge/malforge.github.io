## Summary

```csharp
public static bool IsFontAvailable(string font)
```

Whether a font of this name is loaded in the current session. Worth checking once when a mod starts rather than relying on a name that a world's mod set may not provide.

## Returns

[bool](https://docs.microsoft.com/en-us/dotnet/api/System.Boolean?view=netframework-4.6)

## Parameters

* [string](https://docs.microsoft.com/en-us/dotnet/api/System.String?view=netframework-4.6) font
