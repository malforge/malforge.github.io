## Summary

```csharp
public static Vector2 RotateInput(int degrees, Vector2 rotationIndicator)
```

Rotates a screen space aiming input into the axes of a mount that does not roll with the view, so the aim keeps following the direction the player pushed on screen.

## Returns

[Vector2](VRageMath.Vector2)

## Parameters

* [int](https://docs.microsoft.com/en-us/dotnet/api/System.Int32?view=netframework-4.6) degrees
* [Vector2](VRageMath.Vector2) rotationIndicator
