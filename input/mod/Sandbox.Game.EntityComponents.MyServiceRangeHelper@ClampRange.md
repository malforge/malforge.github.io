## Summary

```csharp
public static float ClampRange(float range)
```

Clamps a service range to [0, MAX_SERVICE_RANGE], falling back to the max for non-finite input (e.g. a tampered network value).

## Returns

[float](https://docs.microsoft.com/en-us/dotnet/api/System.Single?view=netframework-4.6)
