VRage.Game.Entity

MyEntityLifetimeTracker

Assembly: VRage.Game.dll

public abstract sealed class MyEntityLifetimeTracker

Diagnostic counter of entity lifetimes used to spot leaks: entities that are closed but never reclaimed by the GC because something still references them. Lives in the same assembly as MyEntity so the constructor hook is a cheap field read. Disabled by default; gate is checked first so there is no cost when off. All public mutators are safe to call from any thread (entities are created in parallel); Scan() must run on the update thread only.
