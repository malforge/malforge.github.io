MyScreenSpace

Assembly: Sandbox.Game.dll

public abstract sealed class MyScreenSpace

Converts between the two coordinate spaces used by MyScreenSpaceText and MyScreenSpaceSprite , for laying out content that mixes them, and reports the cursor position in those same coordinates for hit testing what a mod has drawn. It also clips drawing to a rectangle, which is what scrolling lists, progress fills and panels that content must not spill out of are built from.

Normalized [0,1] isa fraction of the window. It is relative to the game's safe GUI rectangle, which is a centred, roughly 4:3 area, so on a wide screen normalized 0 sits well inside the left edge. Pixel coordinates are true window pixels. Computing one from the other by multiplying by the viewport size is therefore wrong; use these methods.
