public interface IMyGeneratedTexture: IDisposable

A texture whose pixels a mod writes itself, created through Create(string, Vector2I, MyGeneratedTextureFormat) . Give Name anywhere the game takes a texture path — an LCD sprite of typeVRage.Game.GUI.TextPanel.SpriteType.TEXTURE, for instance — and the renderer resolves it to this texture.Content that is already an image, such as a rendered map or a decoded video frame, costs one upload here against one textured quad per pixel if it were encoded as sprites for the panel to draw back into pixels.

Methods

Member Description
BeginUpdate() Borrows a ByteCount -byte buffer to write the next image into. Fill it, then hand it to EndUpdate(Byte[]) ; do not keep it afterwards, and do not assume it still holds what you last wrote — the same few buffers are cycled as the renderer finishes with them.Pixel order is top-down, tightly packed, four bytes per pixel as R, G, B, A.

Colour channels must be premultiplied by alpha: the sprite pass treats these as premultiplied, so straight alpha reads too bright wherever the image is translucent. Fully opaque and fully transparent pixels are the same under both conventions.
EndUpdate(Byte[]) Hands the filled buffer to the renderer, which replaces the whole image with it and rebuilds the mip chain. The buffer belongs to the renderer from here on — write to it again and you will see a torn image.
