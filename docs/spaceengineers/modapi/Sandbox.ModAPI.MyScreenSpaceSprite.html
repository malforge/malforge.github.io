Sandbox.ModAPI

MyScreenSpaceSprite

Assembly: Sandbox.Game.dll

public abstract sealed class MyScreenSpaceSprite

Draws textured quads in screen space through the game's sprite renderer, for backgrounds, icons, bars and gauges that accompany MyScreenSpaceText .

Immediate mode: every call draws for a single frame, so call it every frame, from a session component's Draw() for content over the game, or from the OnDraw of a MyModScreen for the content of a mod's own screen, where the layer should be left at BelowHud so it composites inside that screen. Must be called from the update thread.

Textures are named by the subtype id of a transparent material declared in TransparentMaterials.sbc, the same ids used for billboards, so a mod's own textures need no extra setup beyond that definition. An id matching no such material is looked up as an LCD texture, which covers the whole set an LCD or a Programmable Block can draw, item and faction icons included, then as a GUI texture, which is what the game's own HUD and screens are built from, then as the icon of the definition named "TypeId/SubtypeId", which is what reaches block icons, and finally as the Name of a texture the mod is drawing into itself.
