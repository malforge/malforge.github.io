public struct MyToolbarItemInfo

What one toolbar slot holds. Read one with TryGetItem(int, out MyToolbarItemInfo) and write one with Set(int, MyToolbarItemInfo) , so a slot read from one toolbar can be placed in another as it stands.

A read is a copy taken at the time it was asked for: it does not follow later edits, and changing it changes nothing. Reading costs no allocation, so a mod may read toolbars on an update path.

Kind says which fields carry a value; the rest are left at their defaults. Action arguments are held apart from this, since most actions have none: read them with the GetParameters extension in Sandbox.ModAPI and write them with the matching Set.
